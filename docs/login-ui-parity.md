## 已修复的原生移植差异

GitHub 上 GLaDOS 的旧提交 `1bca5ea` 使用简化的身体/视线状态和不同表单样式。本次发布使用 React 原组件的逐角色坐标、倾斜、强制视线和计时规则；黄色嘴部改为角色的直接子元素，避免随眼睛容器重复位移。

登录请求失败时只更新错误信息，保留账号、密码及动画实例，不再销毁并重建表单。

## 独立 React 仓库的布局差异

其动画核心已与上述规则一致，不存在旧 GLaDOS 移植版的身体/视线问题。独立仓库仍保留以下原始样式，本次在 GLaDOS 中作兼容性修正：

- 密码按钮补充 `translateY(-50%)`，密码容器显式设为块级，确保图标垂直居中。
- 画布补充 `flex: none`；961–1100px 和 1101–1240px 屏幕分别缩放为 0.68 和 0.82，防止窄桌面裁切角色。
- 补充 `100dvh` 和固定基础行高，减少宿主 CSS 与移动浏览器工具栏导致的布局偏差。

## 有意保留的宿主差异

- 品牌、说明和页脚链接采用 GLaDOS 文案，认证仍为 `/api/auth/login`。
- React 的主题由宿主传入；GLaDOS 将主题保存在浏览器本地存储。
- GLaDOS 对“减少动态效果”偏好额外暂停鼠标跟随、眨眼和偷看。
- React 使用状态渲染；GLaDOS 使用原生 DOM 和 `requestAnimationFrame` 合并鼠标更新，不引入 React 依赖。

`test/animated-login.test.js` 对上述核心参数、计时、空密码显隐和动画清理进行确定性回归测试。
