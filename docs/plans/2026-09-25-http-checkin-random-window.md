# HTTP 签到与随机入队时间段

实测网页 POST `/api/user/checkin` 使用 `{ "token": "glados-facility.com" }`，响应包含 `code`、本次奖励 `points` 和积分流水 `list`。网页签到已成功，返回 6 积分、余额 196。旧代码默认 `glados.cloud`，且接口 404/405 时启动浏览器兜底。

采用直接 HTTP 请求，token 默认跟随配置域名，并迁移旧示例值。保留独立 Cookie jar 和 GET 有限重试；POST 结果不明时不重放。删除浏览器签到与旧 OTP 页面方法。优先使用签到返回流水，缺失时兼容旧积分查询接口。

每账号增加窗口结束时间、计划日期、计划分钟。保留原开始时间与时区字段；旧账号以起止相同表示固定时间。每分钟扫描，使用加密随机数抽取窗口内一分钟，持久化后到点进入已有串行队列。跨午夜以起始日期为调度日；重启后窗口内补入队、窗口外不补。设置修改清除尚未执行的计划，但保留当天入队标记。

验证包括当前接口参数与响应、404 不启动浏览器、随机边界、跨午夜时区、计划复用、窗口内补入队、窗口外跳过、禁用账号和 HTTP 表单校验。页面测试验证新增时间字段和保存流程。不会自动兑换积分。
