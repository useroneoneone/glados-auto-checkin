# GLaDOS v1.2.0

- 账号名称后显示官网套餐，邮箱后显示剩余时长；与官网 Days Left 的四舍五入规则一致。
- Cookie Helper 1.9.0 同步导入套餐与剩余天数，登录检测及签到更新属性。
- 每账号独立自动兑换开关，默认关闭，随每日定时签到暂停。
- 签到成功或已签到后，仅在官网显示剩余 1 天时，选择当前积分足够且可用的最长档位一次。
- 服务端直接调用官网兑换接口，无浏览器或额外运行时依赖；成功后刷新属性、积分并通过原 Webhook 通知。
- 兑换请求持久化，超时和重启后通过新积分流水核实，结果待确认时阻止再次提交。
- GitHub Actions 在 linux/amd64 镜像内运行回归测试后发布固定 SHA 镜像、版本镜像和部署包。

已有数据库自动升级，新开关默认关闭。请保留原 `.env`、`APP_SECRET` 和 `data/`。更新后重新加载插件 1.9.0。
